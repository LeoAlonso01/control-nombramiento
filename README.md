# Control de Nombramientos

Aplicación privada para registrar, consultar y dar seguimiento a nombramientos.

## Tecnologías

- Frontend: SvelteKit + TypeScript
- Backend: FastAPI
- Base de datos: PostgreSQL
- Almacenamiento de documentos: Garage (compatible con S3)
- Despliegue: Docker Compose
- Acceso privado: Tailscale

## Seguridad

No guardar credenciales, documentos reales ni datos institucionales sensibles en el repositorio.
